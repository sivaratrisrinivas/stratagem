# Game data (Fog)

Curated Terraria reference data for the companion. Prefer stage-tagged exports so tools can gate content by player progress.

When importing from the [Terraria Wiki](https://terraria.wiki.gg/):

- Text and structured exports are **CC BY-NC-SA 4.0**
- Attribute the wiki and link to source pages
- Do not use wiki assets (sprites, icons) without checking file-level licenses

Suggested files to add:

- `recipes.json` — crafting results with `stageId` tags
- `housing-rules.json` — NPC housing validation rules
- `hints.json` — spoiler-tier hint text per stage
